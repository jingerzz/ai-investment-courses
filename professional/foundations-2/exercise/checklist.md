# Foundations 2: Checklist

Use this to verify you're ready for Week 1. Every item here directly
supports what comes next.

---

## Installation

- [ ] **Claude Desktop is installed and running.** You can open the
  app and see the conversation interface.

- [ ] **You're signed in with your Anthropic account.** The same
  account you use on claude.ai.

- [ ] **The Claude mobile app is installed.** You can open it on your
  phone and see your conversations.

## Sync and Projects

- [ ] **You can access the same project from web, desktop, and mobile.**
  Open a project on one platform, then verify it appears on the others.

- [ ] **Custom instructions carry over.** Check that the instructions
  you set in a project are visible when you open that project on a
  different device.

- [ ] **Conversation history syncs.** Start a conversation on desktop,
  then open it on mobile and verify the full history is there.

## Attachments

- [ ] **You've successfully uploaded a document.** A PDF, CSV, image,
  or text file — dragged into a conversation or added via the
  paperclip icon.

- [ ] **Claude referenced the actual document content.** Its response
  cited specific details from your file, not generic information.

## Workspace Organization

- [ ] **You have 2-3 purpose-specific projects.** Each with a clear
  name and custom instructions tailored to your role.

- [ ] **Instructions include your preferences.** Format preferences,
  coverage scope, risk parameters, or other role-specific details.

## Week 1 Readiness

- [ ] **You can find Settings > Developer in Claude Desktop.** You
  know where the MCP server configuration lives.

- [ ] **You understand why Claude Desktop (not web) is needed for
  Week 1.** The desktop app is the only platform that supports MCP
  server connections — the mechanism for connecting Claude to live
  data tools.

---

## If Something Isn't Working

**Projects don't appear on another device:** Make sure you're signed
in with the same Anthropic account on all devices. Sign out and back
in if needed.

**Attachment upload fails:** Check the file size and format. Try
saving the document in a different format (e.g., export a spreadsheet
as CSV rather than uploading the Excel file).

**Claude doesn't reference your document:** Be specific in your prompt.
Instead of "what do you think?", try "Based on the document I just
uploaded, what was the revenue growth rate?"

**Developer menu is missing:** Make sure you have the latest version
of Claude Desktop. Update the app from claude.ai/download if needed.
