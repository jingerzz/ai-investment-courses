# Foundations 2: Conversation Guide — Cross-Platform Workflows

Example prompts organized by scenario. Each includes a note on which
platform is best suited. Adapt these to your own coverage, instruments,
and workflow.

---

## Morning Prep on Mobile

Best on mobile — quick context before you sit down at your desk.

**Catch up on yesterday's work:**
```
Summarize where we left off yesterday. What were the key conclusions
from our last conversation?
```

**Prep for a meeting:**
```
I have an investment committee meeting in 30 minutes. Give me
three talking points based on the analysis we did on [Company]
this week.
```

**Quick context check:**
```
Remind me — what was the bull case we outlined for [Company]?
I want to reference it in a call.
```

---

## Deep Analysis on Desktop

Best on desktop — use attachments, longer conversations, and detailed
follow-up.

**Earnings analysis with attachment:**
```
[Attach earnings PDF]
Compare this quarter's results to the guidance management gave
last quarter. Where did they beat, miss, or change the narrative?
```

**Multi-document comparison:**
```
[Attach two research notes]
These are two sell-side notes on the same company with different
ratings. Summarize where the analysts agree and where they
disagree. What's the key assumption driving the difference?
```

**Portfolio review with data:**
```
[Attach holdings CSV]
Analyze this portfolio for concentration risk. Show me sector
exposure as a percentage of NAV, the top 10 positions by weight,
and any single-name positions above 5%.
```

**Building a thesis:**
```
[Attach 10-K excerpt]
I'm building a short thesis on this company. Read the risk
factors section and identify the three risks most likely to
materially impact earnings in the next 12 months. For each one,
suggest what data I should monitor.
```

## Meeting Follow-Up on Mobile

Best on mobile — capture ideas while they're fresh, process later.

**Convert notes to action items:**
```
Here are my raw notes from today's portfolio review meeting:
[dictate or type notes]

Organize these into:
1. Action items with owners
2. Positions to revisit
3. Open questions that need research
```

**Quick trade thesis capture:**
```
I just had a conversation about [Company] that changed my view.
The key insight was [describe it]. Help me formulate this as a
structured investment thesis with catalysts and risks.
```

**Flag something for desktop analysis:**
```
I want to analyze [Company]'s capital allocation history over
the last 5 years. Don't do the analysis now — just outline what
data I should gather and upload when I'm at my desktop.
```

## Document Analysis (Desktop or Web)

Best on desktop for complex documents, web for quick one-offs.

**Earnings transcript — management tone:**
```
[Attach transcript PDF]
Read the Q&A section of this earnings call. Identify any questions
where management seemed evasive, gave non-answers, or changed
their language compared to prior calls.
```

**Financial data extraction:**
```
[Attach CSV or PDF with financial data]
Extract a clean summary table with: revenue, EBITDA, net income,
free cash flow, and net debt for each period in this document.
Calculate year-over-year growth rates.
```

**Chart interpretation:**
```
[Attach chart screenshot]
Describe what you see in this chart. What's the trend? Are there
any notable support or resistance levels? Any divergences between
price and the indicators shown?
```

**Regulatory filing review:**
```
[Attach 8-K or proxy statement PDF]
Summarize the material changes disclosed in this filing. Flag
anything that could affect the investment thesis — executive
changes, restatements, related-party transactions, or covenant
modifications.
```
