The difference between AI that's useful and AI that's dangerous comes down to guardrails.

Without Guardrails
User: "What's the ES trade plan?"

AI: "ES is currently at 5,423.50.
I'd suggest buying at 5,400 with a
stop at 5,370 and target at 5,480."

Problems:
• 5,423.50 — where did this come from?
  (AI hallucinated the price)
• "I'd suggest" — AI is giving advice
• No data source or timestamp
• No risk sizing
• Not based on any actual signal
With Guardrails
Python pre-computes everything:

briefing = f"""
Signal: {signal.name} (Tier {signal.tier})
ES Last: {levels.last:.2f}
Entry: {levels.s1:.2f} - {levels.pivot:.2f}
Stop: {levels.s2:.2f}
Risk: ${dollar_risk:.0f} ({risk_pct:.1f}%)
Data: {data_source} as of {as_of}
"""

Every number comes from Python
AI presents — never calculates
Data source + timestamp included
Risk is pre-sized
Stale data (no detection)
AI: "Current ES price is 5,398.50,
suggesting a buying opportunity near
support."

Reality: This price is from Friday.
It's Monday morning. The market
could be anywhere right now.

The user has no idea they're making
decisions on 3-day-old data.
Stale data (with detection)
Tool returns:
{
  "last": 5398.50,
  "data_source": "end_of_day",
  "as_of": "2026-03-06T16:00:00Z",
  "stale_data_warning":
    "Data is from Friday close"
}

AI: "Note: this analysis uses Friday's
close data. Live prices may differ
significantly after the weekend."
The rule: Python does math. AI does interpretation. Every tool return includes data_source and freshness metadata. The AI never states a number it didn't receive from a tool.
