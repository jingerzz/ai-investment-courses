# Glossary

## Agent

A scheduled or event-driven AI workflow that performs a narrow task and produces an output.

## Audit Trail

A record of what ran, what data was used, what output was produced, and what decision followed.

## Dashboard

A hosted visual surface for reviewing current state, metrics, and outputs.

## Deterministic Tool

Code that computes a result the same way each time from the same inputs. Used for prices, signals, levels, and metrics.

## Filing RAG

Retrieval-augmented generation over SEC filings. The system retrieves source text before the model answers.

## Human Decision Loop

The design principle that AI may observe, compute, retrieve, and recommend, but a human decides when capital or publication risk is involved.

## MCP

Model Context Protocol. A standard way to expose tools and data to AI assistants.

## PageIndex

A document indexing pattern that preserves a navigable structure so long filings can be searched and cited section by section.

## Regime

A classification of market state used to frame risk appetite, exposure, and signal quality.

## Service

A long-running process hosted on Zo, such as an API, MCP server, or internal worker.

## Tool Boundary

The line between what code computes and what the AI explains. Good systems keep this boundary explicit.

## Zo Computer

A personal cloud computer where files, tools, services, hosted pages, integrations, and AI workflows live together.
