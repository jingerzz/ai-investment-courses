# Conclusion: From Course Workflow to Operating System

You have now seen the core pattern for AI-powered investment management on Zo:

- keep the workspace durable
- use tools for exact computation
- use RAG for primary-source document answers
- separate services by responsibility
- use agents for scheduled observation
- keep humans in the decision loop

The course examples are intentionally small. The production versions can be larger, faster, and more automated, but the professional standard does not change.

## What to Build Next

The best next build is usually not the most ambitious one.

Pick a workflow that:

- you already perform manually
- uses data you can access
- has a clear decision point
- can produce a short output
- would save time every week

Then build the smallest useful version on Zo.
