# Prompts: Foundations 2

Use these prompts to make your Zo workspace legible to future AI sessions.

## Review Folder Structure

```text
Review this Zo course workspace structure. Are the folder names clear enough for future AI work? Suggest any changes before I start creating servers, dashboards, and agents.
```

```text
Act as a workspace librarian. Tell me where research notes, source documents, scripts, datasets, dashboards, and agent specs should live. Keep the structure simple.
```

## Write Workspace Instructions

```text
Draft a concise README for this course workspace. It should explain the purpose, folder structure, allowed changes, and what requires explicit approval.
```

```text
Convert this workspace README into instructions a future AI assistant can follow without asking me where files belong.
```

## Check Secrets and Channels

```text
Review this planned workflow and identify which values are secrets, which are access tokens, and which can safely live in plain markdown.
```

```text
For each output in this workflow, recommend the right Zo surface: chat, Telegram, email, hosted page, API route, or scheduled agent.
```
