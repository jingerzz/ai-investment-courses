# Exercise: Prepare Your Zo Course Workspace

## Goal

Prepare a clean workspace for the hands-on modules.

## Steps

1. Create the folder structure from the reading.
2. Add a `README.md` to the course folder.
3. In the README, write:
   - the purpose of the workspace
   - the modules you plan to complete
   - where outputs should go
   - what should never be changed without approval
4. Open Zo settings and confirm where secrets and access tokens live.
5. Open the hosting and automations areas so you know where later modules will land.

## Prompt to Use

Ask Zo:

```text
Review this course workspace structure. Tell me whether the folder names are clear enough for future AI work, and suggest any changes before I start creating servers, dashboards, and agents.
```

## Checkpoint

You are done when:

- your workspace has stable folders
- secrets are not stored in files
- you know where hosted services and automations are managed
- you have a README that explains the workspace to a future AI assistant
