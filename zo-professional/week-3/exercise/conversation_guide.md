# Prompts: Week 3

Use these prompts to design a multi-service investment workflow on Zo.

## Define the Workflow

```text
I want to design a Zo-native investment workflow for [workflow]. The decision it supports is [decision]. Help me define the minimum useful version with exact inputs, tools, output, and human review point.
```

```text
Review this proposed workflow. Separate what should be a service, dataset, hosted page, scheduled agent, and plain markdown note.
```

## Stress-Test the Architecture

```text
Identify missing data sources, unsafe AI assumptions, unclear approval points, and operational failure modes in this architecture.
```

```text
For each component in this architecture, state the owner, input, output, failure mode, and how a future AI assistant should verify it.
```

## Reduce Scope

```text
This architecture is probably too large. Cut it down to the smallest version that can produce a useful human decision-support output in one week.
```

```text
Rewrite this architecture as a build sequence: files first, scripts second, service third, page fourth, agent last.
```
