# Prerequisites

## Required

1. Create a Zo Computer account using Jing's referral link:
   https://zo-computer.cello.so/8dcc6g0vZVs

2. Confirm you can access:
   - your Zo workspace
   - the terminal
   - files
   - settings
   - hosting
   - automations

3. Pick an AI model for chat in Zo settings. A free-tier model is enough for ordinary Q&A. A stronger coding model is recommended when building or modifying servers.

## Recommended

- A Claude Sonnet-class model or equivalent for hands-on coding exercises
- Claude Code or Codex configured as optional coding assistants inside the workflow
- Basic terminal comfort: `cd`, `ls`, `python`, `git`, and reading error messages
- A GitHub account if you want to fork and modify the course examples

## Not Required

- Paid market data
- Production trading accounts
- Prior MCP experience
- Prior web app deployment experience
- Prior Python expertise

## Accounts and Access

Zo can store credentials as environment secrets. Do not paste API keys into course files.

For this course, free public data sources are enough:

- Yahoo Finance for price data
- SEC EDGAR for filings
- local files and hosted services on Zo for course artifacts

## Folder Setup

Create a workspace folder for the course inside Zo. A simple structure is enough:

```
AI-Investing-Course/
├── notes/
├── servers/
├── datasets/
├── dashboards/
└── agents/
```

Keep the structure boring. The point is that the AI can find things later.
