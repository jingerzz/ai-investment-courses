# Exercise: Map Your Investment Workflow onto Zo

## Goal

Create a simple map of how your own investment workflow should live on Zo.

## Steps

1. Open your Zo workspace.
2. Create or identify a course folder.
3. Inside your notes folder, create a markdown note called `workflow-map.md`.
4. Write five headings:
   - Data I use
   - Documents I read
   - Metrics I calculate
   - Decisions I make
   - Outputs I want
5. Under each heading, list 3-5 real examples from your investment process.

## Prompt to Use

Ask Zo:

```text
Review this workflow map and identify which parts should be files, scripts, hosted services, dashboards, or scheduled agents. Keep the recommendation practical and prioritize the first two workflows I should automate.
```

## Checkpoint

You are done when you can answer:

- What data should be computed by tools?
- What documents should be retrieved from source?
- What output should be generated for a human decision?
- What should never be delegated to an AI model?
