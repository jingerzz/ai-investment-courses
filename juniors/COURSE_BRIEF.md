# Course Brief — CoWork Handoff Document

This file provides the metadata, structure, and design direction needed
to transform the course folder into polished marketing materials and a
PDF-style learning book.

---

## Audience

**Primary:** High school students, grades 8-10 (ages 13-16).

**Profile:**
- No assumed finance knowledge — investing basics are taught alongside AI concepts
- No programming experience — they will not write or read code
- Comfortable with phones and computers; may not have used a terminal before
- Motivated by curiosity about AI and money; may have custodial investment accounts
- Likely need parent/teacher help with initial software installation

**Tone:** Friendly, clear, encouraging. Think "cool older sibling explaining
something they're excited about" — not a teacher lecturing, not a textbook.
Avoid being condescending. These are smart students; they just lack context.

---

## Value Proposition

High school students learn to build AI tools that track real stocks —
without writing code. They describe what they want in plain English,
and Claude builds it. By the end, they have working tools connected
to real market data that they built themselves.

**One-liner:** *Build AI-powered stock tools — no coding required.*

## Learning Outcomes

| Week | Outcome |
|------|---------|
| 1 | Build a tool that gives Claude access to real stock data. Understand what stocks are and how AI connects to data. |
| 2 | Add safety checks so AI doesn't make math mistakes or show old data. Build a daily stock report. |
| Bonus | Build a private document reader for company reports using AI on your own computer. |
| 3 | Design how multiple AI tools work together. Think about systems, not just individual tools. |
| 4 | Build an AI that monitors stocks and alerts you. Understand why AI needs human approval. |

**Cumulative outcome:** Students understand how AI actually works with
real data, can direct AI to build useful tools, and think critically
about AI capabilities and limitations.

## Design Direction

### Visual style
- Modern, clean, and inviting — not childish, not corporate
- Color palette that feels fresh and approachable
- Code blocks and JSON examples should be clear but not intimidating
- Tables are used frequently — make them clean and scannable
- Consider illustrations or diagrams for concepts like "how AI calls tools"

### Content treatment
- **Reading sections** are the core chapters — use shorter paragraphs
  and more subheadings than the professional version
- **Conversation guides** should become "Try This" callout boxes
  within exercises
- **Checklists** should appear at the end of each chapter as "Did It Work?"
- **Reference solutions** can be appendices or expandable sections
- **JSON examples** appear frequently — consider showing a "plain English
  translation" alongside each one for the first few chapters
- **Finance concepts** are woven into the reading — highlight these
  with a distinct visual treatment (e.g., "Investing 101" sidebar boxes)

### Recurring elements to style consistently
- **"Investing 101" sidebars** — quick explanations of finance terms
  in context (these are unique to the junior version)
- **Prompt examples** — blocks showing what to type into Claude Code
- **Tool return examples** — JSON blocks with plain-language annotations
- **"Why this matters" callouts** — connecting technical concepts to
  things teens care about
- **"Try it yourself" prompts** — encouraging exploration beyond the script
- **Risk disclaimers** — brief, honest notes about real investing

### Chapter structure (suggested)
Each chapter should follow this flow:
1. Opening hook — why this is cool / useful (1-2 paragraphs)
2. Concepts — the reading, with finance basics woven in
3. Exercise — hands-on with Claude Code
4. "Try This" — example prompts (from conversation guide)
5. "Did It Work?" — the checklist
6. Reference — what a good result looks like (collapsible/appendix)

## Marketing Materials — Key Messages

**Headlines (pick/adapt):**
- "Build AI-Powered Stock Tools — No Coding Required"
- "Learn AI + Investing in 4 Weeks"
- "From Stock Curious to AI Builder"

**Key selling points:**
1. No programming required — Claude builds everything from plain English
2. Real stock data — not fake numbers; uses Yahoo Finance
3. Learn investing AND AI simultaneously
4. Privacy-aware — bonus module runs AI entirely on your computer
5. Cumulative build — each week adds to what you made before
6. 30 + 30 format — manageable weekly commitment

**What this is NOT:**
- Not a coding class
- Not financial advice or a get-rich-quick scheme
- Not dumbed down — same real technology as the professional version
- Not theoretical — every week produces a working tool
