# Foundations 2: Claude Desktop and Mobile -- Setting Up Your Stock Research Workspace

---

## F2.1 Why Desktop Matters

In Foundations 1, you used Claude through your web browser at claude.ai.
That's great for quick questions. But here's the thing -- the whole
point of this course is connecting Claude to **real stock market tools**.
And that only works in the desktop app.

Claude comes in three versions:

- **claude.ai (web)** -- The browser version you already know. Good for
  quick questions and light research. Think of it as the "try it out"
  version.

- **Claude Desktop (Mac/Windows app)** -- This is the app where your
  AI stock tools will live. It looks a lot like the web version, but
  it has one superpower the browser doesn't: **MCP tool connections.**
  In Week 1, you'll connect Claude Desktop to a live stock tool that
  feeds it real market data. That connection only works here.

- **Claude Mobile (iOS/Android)** -- Same account, same conversations.
  Great for checking your stock ideas between classes, asking quick
  follow-ups, or using voice input when you have a question.

Why are we installing the desktop app right now? Because in Week 1,
you'll open Claude Desktop, ask "What's today's market signal?", and
get a real answer from a real tool -- not from Claude's training data.
If you only have the browser version, you'll be stuck.

All three versions share your account, your projects, and your
conversation history. Anything you do in one place shows up everywhere.
The difference is what each one can do -- and Desktop can do the most.

## F2.2 Installing Claude Desktop

### Download and Install

1. Go to [claude.ai/download](https://claude.ai/download).
2. Download the installer for your computer (Mac or Windows).
3. **Mac:** Open the downloaded file and drag Claude into your
   Applications folder. Then open it from Applications.
4. **Windows:** Run the installer and follow the prompts. It's a
   standard install -- just click through.
5. Open Claude Desktop and sign in with the **same Anthropic account**
   you used on claude.ai.

That's it. You should see a clean conversation window that looks
similar to what you've been using in the browser, but as its own app.

### Troubleshooting

- **"I don't have an account yet."** Go to claude.ai first and create
  one. Then come back and install the desktop app.
- **"It says I need to update my OS."** Claude Desktop requires a
  fairly recent version of macOS or Windows. Check that your computer
  is up to date.
- **"I'm on a Chromebook."** Claude Desktop doesn't run on ChromeOS.
  Talk to your instructor about alternatives -- you can use claude.ai
  for most things, but you'll need access to a Mac or PC for the
  MCP tool connection in Week 1.

## F2.3 Quick Interface Tour

Take a minute to look around the Claude Desktop window. Here's what
you'll see:

- **Sidebar (left side):** Your conversation history and project list.
  Click any conversation to pick up where you left off. Click a project
  to work inside it. If you created a project in Foundations 1, it
  should already be here.

- **Project selector:** At the top of the sidebar. This is how you
  switch between projects. Each project has its own custom instructions,
  so switching projects changes how Claude behaves.

- **Model selector:** Lets you pick which version of Claude to use.
  Don't worry about this for now -- the default works great.

- **Attachment button (paperclip icon):** In the message bar at the
  bottom. This is how you'll share files with Claude -- news articles,
  screenshots, class notes, whatever you want Claude to look at.

- **Settings (gear icon):** Open this up. Poke around. You'll see
  account info, preferences, and one section that's especially
  important...

### The Developer Menu

Go to **Settings > Developer**. You'll see a section about MCP server
configuration. It's empty right now, and that's fine.

In Week 1, you'll connect Claude Desktop to a live stock tool. The
Developer menu is where that connection happens. For now, just remember
where it is. When Week 1 arrives, you'll know exactly where to go.

The browser version of Claude doesn't have this menu. That's the
fundamental reason we're using the desktop app.

## F2.4 Projects Sync Across Devices

Remember the project you created in Foundations 1? Open Claude Desktop
and check the sidebar -- it should be right there, with your custom
instructions and conversation history intact. This happens automatically
because you're signed into the same account.

### What Syncs

- Projects and their names
- Custom instructions you set for each project
- Conversation history inside each project
- Favorited conversations (if you've marked any)

### What Doesn't Sync

- MCP tool connections (these are saved on your specific computer --
  you'll learn more about this in Week 1)
- Files stored on your computer's hard drive

### How This Works in Practice

Here's a pattern that works really well:

1. **Desktop (after school):** Open your "Stock Research" project.
   Upload a news article about Apple. Have a detailed conversation
   about what the article means for investors.

2. **Mobile (on the bus):** Open the same project on your phone. Ask
   "What were the key takeaways from that Apple article?" Claude has
   the full conversation and answers right away.

3. **Web (at the library):** Open claude.ai on any computer. Pull up
   the same project to reference your earlier analysis for a class
   assignment.

The project is the container. The device is just how you access it.

## F2.5 Working with Attachments

One of the coolest things Claude can do: you can give it actual
documents to read and analyze. This turns Claude from "an AI that
knows general stuff" into "an AI that reads what you give it and
talks about *that specific thing*."

### How to Add Files

- **Desktop:** Drag a file directly into the conversation, or click
  the paperclip icon to browse your files. You can add multiple files
  at once.
- **Mobile:** Tap the attachment icon and pick a file from your phone.
  Works with local files, iCloud, or Google Drive.
- **Web:** Click the paperclip icon or drag and drop.

### Supported Formats

| Format | Good For |
|--------|----------|
| **PDF** | News articles, research reports, class handouts |
| **Images** (PNG, JPG) | Stock chart screenshots, infographics, photos of whiteboard notes |
| **Text files** (.txt, .md) | Notes, outlines, drafts |
| **CSV** | Stock price data, spreadsheets (save as CSV first) |
| **Code files** (.py, .json) | Relevant in later weeks when you work with tools |

### Tips for Getting Good Results

**News articles:** Screenshot an article or save it as a PDF. Ask
Claude to summarize the key points: "What does this article say about
Tesla's new factory?" or "How might this news affect Apple's stock
price?" Claude reads the actual article -- it's not guessing.

**Stock chart screenshots:** Take a screenshot from Yahoo Finance,
Google Finance, or any charting site. Ask Claude what it sees: "What's
the trend in this chart?" or "Does this look like the stock is going
up or down over the past month?" Note: Claude can describe visual
patterns, but it can't read exact numbers from a chart image. If you
need precise data, paste the numbers as text too.

**Class notes:** Snap a photo of your notes or upload a document. Ask
Claude to help you organize them, fill in gaps, or explain concepts
you didn't fully get.

### Size Limits

Claude can handle pretty long documents. A typical news article or
class handout is no problem. For really long documents, you can upload
just the part you care about, or tell Claude to focus on a specific
section.

## F2.6 The Claude Mobile App

### Getting Started

1. Download from the [App Store](https://apps.apple.com/app/claude/id6473753684)
   (iOS) or [Google Play](https://play.google.com/store/apps/details?id=com.anthropic.claude)
   (Android).
2. Sign in with your Anthropic account.
3. Your projects and conversations appear automatically.

### What Works Well on Mobile

**Quick follow-ups.** If you were researching a stock on desktop, you
can ask follow-up questions on your phone without starting over. The
conversation history is already there.

**Voice input.** Use your phone's dictation instead of typing. This is
great when you have a quick question: "What were the main reasons we
said Apple was a good investment?" is way faster to speak than type.

**Check your ideas between classes.** Got five minutes before your
next class? Open Claude and ask a quick question about a stock you're
watching or a concept you're learning about.

**Capture ideas on the go.** When you hear something interesting about
a company or the market, open Claude and dictate your thoughts. Ask
Claude to help you organize them later.

### What's Better on Desktop

**Long documents.** Reading and analyzing a big article or report is
easier on a bigger screen with drag-and-drop file management.

**Detailed research sessions.** If you're going back and forth with
Claude for 20+ minutes, building out a stock analysis with multiple
attachments -- do that on desktop.

**MCP tool connections.** The live stock tools you'll connect in Week 1
only work on Claude Desktop. Mobile can't connect to those tools.

### The Right Way to Think About It

Mobile isn't a worse version of desktop. It's a different tool for
different moments. Checking a quick fact while waiting for the bus,
capturing an idea you had during class, reviewing an analysis before
a stock club meeting -- these are all things mobile does well that
desktop can't, because you don't have your laptop with you.

## F2.7 Building Your Workspace

Now that you have Claude on your computer and phone, let's set up some
projects. The idea is to give Claude different "modes" for different
kinds of work, each with its own instructions.

### Project 1: "Stock Research"

This is your main project for this course. It's where you'll do most
of your investment analysis.

**Custom instructions:**
```
I'm a student learning about stock investing. When I share news
articles, stock charts, or company information, help me understand
what it means for investors.

How to help me:
- Explain financial terms when you use them
- When I ask about a stock, break it down into pros and cons
- Use plain language, but don't oversimplify
- If I share a chart or article, focus on what's actually in it
- Remind me that stock analysis is about learning, not guarantees
```

### Project 2: "School Stock Club"

If you're in a stock club, investing competition, or group project,
this is your collaboration space.

**Custom instructions:**
```
I'm part of a school stock market club. We pick stocks as a team
and track how they do. Help me prepare for club meetings and
analyze our picks.

When I share our portfolio or stock ideas:
- Compare stocks fairly (don't just say everything is great)
- Help me build presentations for the group
- Suggest questions I should ask about each stock pick
- Keep track of the reasoning behind our decisions
```

### Project 3: "Learning Journal"

A place to track what you're learning about investing and AI tools
throughout this course.

**Custom instructions:**
```
This is my learning journal for an AI investing course. Help me
reflect on what I'm learning and connect new concepts to things
I already know.

When I share notes or ask questions:
- Help me summarize key concepts in my own words
- Point out connections between topics
- Quiz me on things I should remember
- Be honest if I'm misunderstanding something
```

### Pick at Least Two

You don't need all three. Create "Stock Research" for sure -- that's
your main project for this course. Then pick whichever of the other
two fits your situation. You can always create more later.

### Improving Your Instructions Over Time

Your first set of instructions won't be perfect, and that's totally
fine. Here's how to improve them:

1. Start with the templates above (or write your own).
2. Use the project for a few conversations.
3. Notice when Claude does something unhelpful -- too much jargon,
   wrong format, makes assumptions you don't like.
4. Update the instructions to fix those patterns.
5. Repeat.

Think of it like training a study partner. You don't explain everything
upfront. You give basic guidance, see how it goes, and adjust.

## Key Takeaways

1. **Claude Desktop is required for this course.** The MCP tool
   connections that power Week 1 through Week 4 only work in the
   desktop app. Install it now.

2. **Projects keep your work organized.** Create focused projects with
   clear instructions. They sync across all your devices automatically.

3. **Attachments let Claude read your actual documents.** Upload news
   articles, chart screenshots, and class notes. Claude analyzes what
   you give it -- it's not making things up.

4. **Mobile extends your workspace.** Use it for quick questions,
   voice input, and checking your stock ideas between classes. Save
   the heavy research for desktop.

5. **The Developer menu is your Week 1 on-ramp.** Settings > Developer
   is where you'll connect Claude to a live stock tool next week. You
   don't need to touch it yet, but you know where it is.

6. **Custom instructions get better with use.** Start with the
   templates, see what works, and refine. The best instructions come
   from real conversations, not from planning everything in advance.
