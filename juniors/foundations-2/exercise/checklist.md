# Foundations 2: Checklist

Use this to make sure you're ready for Week 1. Every item here
directly supports what comes next.

---

## Installation

- [ ] **Claude Desktop is installed and running.** You can open the
  app and see the conversation interface.

- [ ] **You're signed in with your Anthropic account.** The same
  account you use on claude.ai.

- [ ] **The Claude mobile app is installed (optional).** You can open
  it on your phone and see your conversations.

## Sync and Projects

- [ ] **You can access the same project from web and desktop.** Open
  a project on one platform, then verify it appears on the other.

- [ ] **Custom instructions carry over.** Check that the instructions
  you set in a project are visible when you open that project on a
  different device.

- [ ] **Conversation history syncs.** Start a conversation on desktop,
  then check it on the web (or mobile) and verify the full history
  is there.

## Attachments

- [ ] **You've successfully uploaded a document.** A news article,
  chart screenshot, class notes, or text file -- dragged into a
  conversation or added via the paperclip icon.

- [ ] **Claude referenced the actual document content.** Its response
  cited specific details from your file, not generic information.

## Workspace Organization

- [ ] **You have at least 2 projects set up.** Each with a clear name
  and custom instructions.

- [ ] **"Stock Research" project is ready.** This is your main project
  for the course, with instructions that tell Claude you're a student
  investor.

- [ ] **Your second project has custom instructions too.** Whether
  it's "School Stock Club," "Learning Journal," or something else.

## Week 1 Readiness

- [ ] **You can find Settings > Developer in Claude Desktop.** You
  know where the MCP server configuration lives.

- [ ] **You understand why Claude Desktop (not web) is needed for
  Week 1.** The desktop app is the only platform that supports MCP
  tool connections -- the mechanism for connecting Claude to live
  stock tools.

---

## If Something Isn't Working

**Projects don't appear on another device:** Make sure you're signed
in with the same Anthropic account on all devices. Try signing out
and back in.

**Attachment upload fails:** Check the file size and format. Try
saving the document in a different format (e.g., screenshot a web
article as a PNG instead of trying to upload the webpage).

**Claude doesn't reference your document:** Be specific in your
prompt. Instead of "what do you think?", try "Based on the article
I just uploaded, what does it say about Tesla's sales numbers?"

**Developer menu is missing:** Make sure you have the latest version
of Claude Desktop. Update the app from claude.ai/download if needed.

**Mobile app doesn't show my projects:** Give it a moment to sync.
If projects still don't appear, sign out and sign back in.
